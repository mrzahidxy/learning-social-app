# Pathshala

Pathshala is a learning/social app built with SvelteKit, Prisma, PostgreSQL, and Supabase.

## Features

- Authentication
- Articles
- Author subscriptions
- Notifications

## Stack

- SvelteKit
- Svelte 5
- TypeScript
- Prisma
- PostgreSQL
- Supabase
- Tailwind CSS
- Vite

## Environment

- `PUBLIC_SUPABASE_URL`
- `PUBLIC_SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY`
- `DATABASE_URL`
- `DIRECT_URL`

## Setup

Create `.env` from `.env.example`, then run:

```sh
npm install
npm run dev
```

## Scripts

- `npm run dev`
- `npm run check`
- `npm run build`
- `npm run test`
- `npm run seed`
